# CATSPERB variant in unexplained male infertility

Code accompanying an accepted manuscript:

> Mousavi SZ, Kouhi P, Esmaeili V, Rokhsattalab Z, Esmaeilzadeh A, Almadani N, Mohammad Soltani B, Totonchi M.  
> Identifying CATSPERB variants in unexplained male infertility through familial exome sequencing.  
> *BioImpacts*. 2026. (accepted)

## What this repository contains

Computational analysis related to familial exome sequencing and CATSPERB variant interpretation.

## Data policy

Private until publication.  
Do not upload identifiable familial VCF files, pedigrees with names, or raw exomes.

## Citation

Cite the published article when the DOI is available.
